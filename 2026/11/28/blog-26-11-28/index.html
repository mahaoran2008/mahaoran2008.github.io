匿名函数

Python 使用 lambda 来创建匿名函数,即不再使用def形式定义。

lambda 的主体是一个表达式，而不是一个代码块。仅仅能在 lambda 表达式中封装有限的逻辑进去。

lambda 函数拥有自己的命名空间，且不能访问自己参数列表之外或全局命名空间里的参数

lambda 函数的语法只包含一个语句

其中

lambda是python的关键字

arguments是参数列表，可以包含零个或多个参数，但必须在冒号(:)前指定

expression是一个表达式，用于计算并返回函数的结果

设置两数之和

可以将匿名函数封装在一个函数内，这样可以使用同样的代码来创建多个匿名函数

强制位置参数

/ 用来指明函数形参必须使用指定位置参数，不能使用关键字参数的形式

其中a 和 b 必须使用指定位置参数，c 或 d 可以是位置形参或关键字形参，而 e 和 f 要求为关键字形参

模块可以避免命名冲突，不同模块中的同名函数或变量不会互相干扰

将代码按功能划分到不同的模块中，使程序结构更清晰

在源文件里使用import语句，即可使用python源文件

__ ___name_____属性

一个模块被另一个程序第一次引入时，其主程序将运行。

如果我们想在模块被引入时，模块中的某一程序块不执行，我们可以用__ ___name_____属性来使该程序块仅在该模块自身运行时执行

每个模块都有_name_____属性

如果模块是被直接运行，__name__ 的值为 __main__

如果模块是被导入的，__name__ 的值为模块名
